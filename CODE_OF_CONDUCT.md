# Code of conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive and specific. Harassment, discrimination, personal
attacks and publication of private information are not acceptable.

Project maintainers may remove comments, close issues or block participants who
violate these expectations.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
