# Models

Place trusted GGUF files in this directory. Model weights are intentionally
excluded from Git and GitHub Releases.

The tested configuration used:

- 35B-class MoE GGUF
- IQ2_M-class quantisation
- approximately 11.6 GB model file
- context starting at 8192 tokens

Verify the model licence before downloading or redistributing it. Do not commit
private or unlicensed weights.
